# Ejercicios y prácticas

## Ejercicio 1: Crear proyecto 

**Instrucciones:**
- 1.- Para crear un nuevo proyecto, dirígete al menú principal y haz clic en la pestaña "Proyecto". Una vez que se despliegue el menú, selecciona "Crear nuevo proyecto" o utiliza el atajo Ctrl+N. Esto abrirá una ventana del explorador de archivos.
- 2.- En esta nueva ventana, escribe el nombre que deseas darle a tu proyecto en el campo de texto ubicado en la parte inferior.
- 3.- Finalmente, para completar la creación del proyecto, haz clic en el botón "Guardar".
